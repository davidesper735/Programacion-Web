Glosario de términos HTML

Haz un pequeño "Glosario de términos HTML" usando dl/dt/dd — mínimo 5 términos con su definición.

HTML
Lenguaje de marcado que se usa para crear la estructura y el contenido de las páginas web.
Etiqueta (tag)
Palabra clave encerrada entre < y > que define un elemento, como p o img.
Atributo
Propiedad que se agrega a una etiqueta para proporcionar información adicional sobre el elemento, como src en img src="imagen.jpg".
Elemento
Una parte específica de un documento HTML, definida por una etiqueta de apertura y cierre, como p y /p.
Contenido
El texto o los elementos multimedia que se muestran en una página web.
